# 前言

如果你也想要拥有一个免费、速度快且设计美观的静态博客，那么 **Astro + Cloudflare Pages** 是目前的最佳选择之一。本教程将基于 [Fuwari](https://github.com/saicaca/fuwari) 主题，带你从零搭建属于自己的博客。

**你需要准备：**
1.  **GitHub 账号**：用于存放博客源码。
2.  **Cloudflare 账号**：用于免费托管和加速网站。
3.  **一台电脑**：用于操作。
4.  **通畅的网络环境**：确保能顺利访问 GitHub。

> 本博客使用的仓库地址：[fuwari](https://github.com/lie-jiu/fuwari) (lie-jiu仓库)

---

## 第一步：复刻 (Fork) 项目

首先，登录你的 GitHub 账号，访问上面的仓库地址。

点击页面右上角的 **Fork** 按钮。

![](src/content/posts/assets/images/github复刻.png)

* **Repository name**（仓库名称）：建议保持默认 `fuwari`，或者修改为你喜欢的名字（如 `my-blog`）。
* 点击 **Create fork**，大约 3 秒钟即可将项目复制到你的账号下。

---

## 第二步：在 Cloudflare 中部署

### 1. 创建应用
[点击进入 Cloudflare 仪表盘](https://dash.cloudflare.com/)。

在左侧侧边栏中找到 **Workers 和 Pages** (Workers & Pages)。

![](src/content/posts/assets/images/cloudflare-pages.png)

点击页面右上角的蓝色按钮 **创建应用程序** (Create application)。

![](src/content/posts/assets/images/PixPin_2025-11-13_15-56-01.png)

### 2. 连接 Git 仓库
在页面中选择 **Pages** 标签页，点击 **连接到 Git** (Connect to Git)。

接下来会跳转至 GitHub 进行授权：
* 建议选择 **Only select repositories** (仅选择特定仓库)，只勾选刚才 Fork 的 `fuwari` 项目。
* 点击 **Install & Authorize**。

### 3. 配置构建环境
授权完成后，你会看到选择存储库的界面。

![](src/content/posts/assets/images/PixPin_2025-11-13_16-00-20.png)

:::tip
**注意**：如果发现“开始设置”按钮是灰色的，请先点击一下列表中的 **fuwari** 项目，直到右侧出现绿色的对钩 ✔️，此时按钮即可点击。
:::

进入构建配置页面：

![](src/content/posts/assets/images/PixPin_2025-11-13_16-03-52.png)

* **项目名称**：可以自定义。
* **生产分支**：默认为 `main` 或 `master`。
* **框架预设 (Framework Preset)**：**这里非常重要，请选择 `Astro`**。
    * 构建命令：`npm run build`
    * 输出目录：`dist`

确认无误后，点击 **保存并部署** (Save and Deploy)。

---

## 第三步：等待部署完成

Cloudflare 会自动开始拉取代码并构建。通常只需要等待 1 分钟左右。

当看到 **"Success!"** 字样时，恭喜你，你的博客已经上线了！点击 Cloudflare 分配的 `*.pages.dev` 域名即可直接访问。

---

## 第四步：个性化配置 (必做)

现在的博客还是默认的演示内容，你需要修改配置文件来变成你自己的。

**核心配置文件**：`src/config.ts`

### 修改方式
你可以选择以下两种方式之一：
1.  **GitHub 网页版修改**（推荐新手）：直接在 GitHub 仓库中找到文件，点击右上角的“铅笔”图标✏️进行编辑，改完点击 `Commit changes` 保存。
2.  **本地编辑器修改**（推荐进阶）：使用 VS Code 克隆仓库到本地，修改后推送（Push）回 GitHub。

![](src/content/posts/assets/images/PixPin_2025-11-13_20-42-55.png)

### 关键配置项
在 `src/config.ts` 中，请重点关注以下内容：

```typescript
export const siteConfig: SiteConfig = {
  title: '你的博客标题',   // 必改：网站左上角显示的标题
  subtitle: '副标题',      // 选填
  lang: 'zh_CN',          // 语言设置
  themeColor: {
    hue: 250,             // 主题色调 (0-360)
    fixed: false,
  },
  banner: {
    enable: true,
    src: 'assets/images/demo-banner.png', // 首页大图路径
  },
  // ... 其他配置
}
